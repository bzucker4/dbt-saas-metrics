How to read retention

Net revenue retention (NRR) includes expansion, contraction and churn for the starting revenue cohort. Gross revenue retention (GRR) excludes expansion. A value above 100% means the retained cohort grew on a net basis; it does not mean total company revenue grew by that percentage.

Activation definition

The demo treats a user as activated when the configured activation event occurs within the activation window after signup. Events that occur before signup must not be selected as the user's valid activation. The demo's regression fixture checks this edge case.

About the project

A reusable dbt starting point for SaaS metrics

dbt SaaS Metrics contains models for MRR movements, retention, user activation, product-led funnel conversion, and customer health. This page is a lightweight interactive showcase built from the repository's synthetic DuckDB demo results. It is not a live analytics product and does not connect to a warehouse.
